# 链接拼写规则

本工程有三类链接，规则都是：**值一律 `encodeURIComponent`、空值不拼、缺关键参数直接报错不跳**（不带着坏参数去跳，避免用户在对面看到白页）。

| 场景 | 链接形态 | 拼装位置 |
| --- | --- | --- |
| 跳鹅直播小程序 | `pages/webView/webView?appId=&aliveId=[&ko_token=][&share_user_id=]` | `mp-demo/src/utils/livePath.ts` |
| 内嵌 H5（web-view） | `{VITE_H5_BASE}{路径}?app_env_type=&app_id=` | `mp-demo/src/utils/config.ts` |
| 登录后回跳 | `/pages/xxx?query=` 经 `encodeURIComponent` 一次后放进 `redirect_uri` | 调用方 + `pages/login/index.vue` |

## 1. 跳转小鹅通的【鹅直播】小程序

统一用 `uni.navigateToMiniProgram`，三个入参：

```js
uni.navigateToMiniProgram({
  appId: 'wx13a74d0d3ab0942e',       // 目标小程序：VITE_LIVE_MP_WX_APP_ID
  path: 'pages/webView/webView?appId=appq6jjgwoo7664&aliveId=l_xxx&ko_token=...',
  envVersion: 'release',             // 固定 release（写死在 globalData.ENV_VERSION）
})
```

| 入参 | 来源 | 说明 |
| --- | --- | --- |
| `appId` | `VITE_LIVE_MP_WX_APP_ID` | 正式 `wx13a74d0d3ab0942e`，测试 `wxb58a41ffda339bf5` |
| `path` | `buildLivePath()` | 见下 |
| `envVersion` | 固定 `release` | 鹅直播只接受正式版跳转，不开放配置 |

### path 拼装

```
pages/webView/webView?appId=<店铺 app_id>&aliveId=<直播间 id>[&ko_token=<token>][&share_user_id=<uid>]
```

- **直播 / 录播 / 回放是同一个路径**，只有 `aliveId` 不同（`pages/webView/webView` 在目标小程序里自己分流）
- `appId` = 店铺 ID（`VITE_XIAOE_APP_ID`，如 `appq6jjgwoo7664`），不是微信 appid
- `aliveId` 取法：后台打开直播间 H5 链接 `.../v2/course/alive/<alive_id>?...`，`alive/` 后面那一段，写在 `mp-demo/src/config/live.ts`
- `ko_token` / `share_user_id` 为空时**整段不拼**，不留 `ko_token=`
- 缺 `appId` 或 `aliveId` 时 `buildLivePath()` 直接抛错，调用方不会发起跳转

`PAGE_PATH` 常量在 `utils/livePath.ts`（`pages/webView/webView`，注意大小写：小程序的页面路径是大小写敏感的）。


### 示例

```js
// 已登录、同店铺
'pages/webView/webView?appId=appq6jjgwoo7664&aliveId=l_6ae8ad5be4b0694c3556835a&ko_token=ko_abc123'

// 未登录 / 跨店铺
'pages/webView/webView?appId=appq6jjgwoo7664&aliveId=l_6aab9cbbe4b0694c354a7e5a'
```

## 2. 内嵌 H5（web-view）

### 地址构造

```
{VITE_H5_BASE}{路径}?app_env_type=mini_program_wechat_sdk&app_id=<店铺 app_id>
```

- `VITE_H5_BASE`：业务 H5 / 微页面自定义域名（唯一来源，没有兜底域名），如 `https://xiaoe.david-tech.cn`
- 课程详情页路径：`/p/course/ecourse/preview/{VITE_H5_COURSE_ID}`（`buildCourseH5Url()`）；只配域名不配课程 ID 时退回域名首页
- `withEmbedParams()` 补两个参数，**幂等**：`app_env_type` 已存在就不再加，`app_id` 同理；`#` 片段会被保留

最终形态：

```
https://xiaoe.david-tech.cn/p/course/ecourse/preview/course_3JIjajI4vEN1msWegKHBt0Br6ug
  ?app_env_type=mini_program_wechat_sdk&app_id=appq6jjgwoo7664
```

### 域名白名单

`isAllowedWebViewUrl()`：必须 `https://`，且 host 等于或属于 `H5_BASE` / `API_BASE` 的域名（子域名放行）。不在白名单不给加载，并在页面上提示去配业务域名。

小程序后台还要把该域名加进**业务域名**（web-view 用），否则真机打不开；开发者工具里需勾「不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书」。

### 加载前必须做登录态交接

H5 侧没有登录态时，小鹅通边缘会把任何入口重定向到 `/p/free/sdk/applet_login`，看起来就是「每次打开都要登录」。所以 web-view 的 `src` 不是直接填上面的地址，而是：

```
未登录 → 跳小程序登录页（带 redirect_uri 回 webview 页）
已登录 → POST /api/login-url  → 后端调小鹅云 xe.login.url 换回业务页地址 → 用它当 src
        失败则降级加载原地址（H5 自己处理登录态）
```

换址规则（后端 `login_service.login_url()`）：

| 项 | 值 | 说明 |
| --- | --- | --- |
| `login_type` | **4** | 1/2/5 返回 PC 登录页（`{店铺}.pc.xiaoe-tech.com/login_cooperate/pc_login`）、3 返回平台 H5 登录页，塞进 web-view 都出不来 |
| `redirect_uri` | 上面的 H5 地址，但**去掉 `app_env_type`** | 平台换址时会自己补一个，传两个就重复成 `app_env_type=..&app_env_type=..` |

换回来的地址形如（`state` 是一次性票据，落地点种 `ko_token` cookie）：

```
https://xiaoe.david-tech.cn/p/course/ecourse/preview/course_xxx
  ?app_env_type=mini_program_wechat_sdk&app_id=appq6jjgwoo7664&state=<ticket>
```

排查用：后端成功会记 `h5_login_url_built`（只记 host/path/参数名，不记 ticket），失败记 `biz_failed`。

## 3. 登录后回跳（redirect_uri）

规则：**只编码一次、只解码一次**。

```ts
// 发起方：把「回跳页 + 它的参数」整体编码一次，塞进 redirect_uri
const back = '/pages/webview/index?url=' + encodeURIComponent(h5Url) + '&retry=1'
uni.redirectTo({ url: '/pages/login/index?redirect_uri=' + encodeURIComponent(back) })

// 登录页：解码一次，登录成功后原样 redirectTo
redirectUri.value = decodeURIComponent(query.redirect_uri)
uni.redirectTo({ url: redirectUri.value })
```

常见错误：对已经 `encodeURIComponent` 过的串**再编一次**，回跳地址会变成 `%252Fpages%252F...`，`redirectTo` 失败后只能 `reLaunch` 首页 —— 表现就是「登录完没回到原来的页面」。

## 4. 小鹅云 WebSDK 官方链接规则（对照用）

来源：[WebSDK接入](https://api-doc.xiaoe-tech.com/recall_scene/lnline_sdk/h5_sdk.html)

### 域名规则

- 店铺首页：`https://{appId}.{h5}.xiaoeknow.com`
- 其他页面：从店铺管理台「课程分享 → 复制链接」拿到原始链接（或微信打开H5页面时复制链接参看格式），把**域名部分**替换成 `https://{appId}.{h5}.xiaoeknow.com`，后面的路径与参数原样保留
- 店铺绑定了独立域名时：把前缀域名换成独立域名，**后面的拼接规则不变**

### H5 资源链接

| 资源 | 路径 |
| --- | --- |
| 图文 | `/p/course/text/{resourceId}` |
| 音频 | `/p/course/audio/{resourceId}` |
| 视频 | `/p/course/video/{resourceId}` |
| 电子书 | `/p/course/ebook/{resourceId}` |
| AI 互动课 | `/p/course/ai_course/{resourceId}` |
| 专栏 | `/p/course/column/{resourceId}` |
| 大专栏 | `/p/course/big_column/{resourceId}` |
| 训练营 | `/p/course/camp/{resourceId}` |
| 会员 | `/p/course/member/{resourceId}` |
| 直播 | `/v2/course/alive/{resourceId}?app_id={appId}` |
| 课程（训练营 Pro） | `/p/course/ecourse/{resourceId}` |
| 圈子 | `/xe.community.community_service/v2/feedList?app_id={appId}&community_id={resourceId}` |

### 登录鉴权链接

`POST https://api.xiaoe-tech.com/xe.login.url/1.0.0`

| 参数 | 必选 | 说明 |
| --- | --- | --- |
| `access_token` | 是 | 开放平台 access_token |
| `user_id` | 是 | 小鹅通侧 user_id |
| `data.login_type` | 是 | 小程序值为4 |
| `data.redirect_uri` | 否 | 登录成功后要跳转的目标页 |

响应：`data.login_url`（**有效期 1 分钟**）、`data.permission_denied_url`（店铺无 SDK 权益包时的跳转地址）。

### 其他相关接口

| 接口 | 用途 |
| --- | --- |
| `POST /xe.websdk.account.logout/1.0.0` | 退出 SDK 登录态（`access_token` + `user_id`） |
| `POST /xe.login.get_xe_login_page/1.0.0` | 取小鹅通登录页地址（`redirect_url`、`visit_client.visit_app`：`wx` / `browser`） |
